# DeskBridge Homebrew tap

On an Apple Silicon Mac running macOS 14 or later, install [DeskBridge](https://github.com/ThanhNg224/DeskBridge) with:

```sh
brew install --cask thanhng224/deskbridge/deskbridge
```

Then open DeskBridge from Applications and follow the [first-time setup guide](https://github.com/ThanhNg224/DeskBridge#get-started). The current app is distributed without Apple notarization.

To upgrade an existing Homebrew installation, run `brew upgrade --cask deskbridge`.

For each macOS release, update the cask version and SHA-256 to match the published `DeskBridge.zip`.
